A maintenance release. The compiler, generated wire format and plugin code are those of 1.3.8;
modules generated by the two releases are interchangeable.

### Changed

- **The toolchain and CLI archives use LuneBlox 0.11.4**, from 0.11.3, and the `@lune` typedef alias
  follows it. Luau remains at 0.740. The runtime backports the conditional-spill code generator fix,
  preserves numeric Instance attributes as Float64, and fixes empty-model DOM cleanup. Its fast flags
  match Roblox client 0.746.0.7461267, including `LuauCodegenIntegerCompare = false`, and its
  `async-executor` dependency moves off the yanked 1.14.0 release to 1.14.1.
- **Documentation dependencies are refreshed**: Astro 7.4.7, Starlight 0.42.9 and the
  `postcss-selector-parser` override 7.1.7, with the lockfile regenerated. The remaining tool and
  workflow action pins were checked and are already the latest stable releases.

### Fixed

- **The optional OCALE workflow verifies the full installer checksum.** Its pinned `rocale-cli`
  0.1.3 SHA-256 was missing the final hex digit, which stopped installation before the cloud
  comparison could run. The corrected digest was verified against the downloaded Linux archive.

### Validation

The full type and test gates pass on 0.11.4, with unchanged goldens; all five CLI archives, the
plugin and documentation build successfully, and npm audit reports zero vulnerabilities. The
local OCALE codec experiment passes all nine checks; no credentialed Roblox run was performed.

The unchanged compiler was timed on LuneBlox 0.11.3 and 0.11.4, on an Apple M1: three full ABBA
rounds of `Runtime` and `Scenarios`, native and interpreted, 200 frames each. Interpreted fire
and decode medians differ by at most 1.1% in `Runtime`; scenario medians agree at their printed
precision apart from sub-microsecond drift on Instances. An initial 3-4% drift in native entity
decode did not reproduce in seven focused ABBA rounds of 400 frames: `Entities` decodes in
3.949 to 3.943 ms, `EntitiesRandom` in 3.948 to 3.941 ms (0.11.3 to 0.11.4, median of fourteen
runs each). Paired-round differences vary in sign; no repeatable slowdown was found. These
measure the runtime update, not a compiler optimization; bytes and remote-call counts do not move.

### Upgrading

No schema, wire format or handler signature changes; existing generated modules need no recompiling.
Run `rokit install` to update the development toolchain.
