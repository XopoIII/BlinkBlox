# Installation
The recommended way to install BlinkBlox is using [Rokit](https://github.com/rojo-rbx/rokit).
<Steps>

### Installing BlinkBlox

Open a terminal in your project directory and run the following command:

```sh copy filename="Bash"
rokit add XopoIII/BlinkBlox blinkblox
```

### Updating BlinkBlox

When a new version of BlinkBlox releases, using Rokit you can easily update using the following command:

```sh copy filename="Bash"
rokit update XopoIII/BlinkBlox
```

</Steps>

## Alternatives

<details>
<summary>GitHub Releases</summary>

You can download pre-built binaries directly from the
[GitHub Releases](https://github.com/XopoIII/BlinkBlox/releases) page.

</details>

<details>
<summary>pesde</summary>

This fork is not published to the pesde registry — that scope belongs to the upstream project, and
publishing fork builds under it would put them in front of everyone installing upstream.

Use Rokit, or the release artifacts below.

</details>

<details>
<summary>Roblox Studio</summary>
BlinkBlox offers a companion studio plugin which allows you to write and generate files within Studio without the need for external tooling.  
The studio plugin can be installed from the [Creator Store](https://create.roblox.com/store/asset/77231976488966/Blink-Editor).  
Alternatively you can download it from [Github Releases](https://github.com/XopoIII/BlinkBlox/releases).
</details>
